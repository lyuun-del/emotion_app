# MoodLand web fonts

The website self-hosts only the glyphs and weights used by the current page. All files use `font-display: swap` and are served as WOFF2.

- **LXGW WenKai Regular** — brand and editorial Chinese headings. Source: <https://github.com/lxgw/LxgwWenKai>. License: SIL Open Font License 1.1.
- **Noto Sans SC Variable** — Chinese body copy and interface text. Source: <https://github.com/google/fonts/tree/main/ofl/notosanssc>. License: SIL Open Font License 1.1.
- **Manrope Variable** — English labels, navigation, and numeric data. Source: <https://github.com/google/fonts/tree/main/ofl/manrope>. License: SIL Open Font License 1.1.

The full license text is included in `OFL-1.1.txt`.
